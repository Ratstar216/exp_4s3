Robot AR Marker Tracker

A desktop control app for tracking ArUco-tagged robots in real time, painting territory from their paths, and showing match state across control, spectator, and projector windows.

Run the tracker Print markers
Camera tracking OpenCV reads a local, URL, or file-based camera source.
Match display Qt windows split control, spectator, and projector views.
Territory game Robot paths paint territory and support item boosts affect play.

Tracking workflow

Built for camera-overhead robot matches.

ArUco marker detection

Detect marker IDs, centers, borders, heading, and frame rate from the live camera feed.

Territory scoring

Draw broad colored trajectories, let robots overwrite territory, and show each player's share during the match.

Operator controls

Place mushroom support items, manually paint or erase territory, reset matches, and calibrate camera/projector points.

Presentation output

Keep the control UI on one screen while spectator and projector windows show match-ready views.

Local setup

Run with uv.

The repository is managed by uv and targets Python 3.13. Install dependencies, then start the tracker with one or more robot IDs. 

uv sync
uv run python hello.py --robot-ids 0 1
uv run python hello.py --list-cameras

Robot tags

Print one marker per robot.

Attach each marker flat on top of a robot. Keep the ArUco dictionary consistent between marker generation and tracking. 

uv run python hello.py --generate-marker 0 --output marker-0.png
uv run python hello.py --generate-marker 1 --output marker-1.png
